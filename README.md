## 项目简介

本项目是一套基于 5G-Advanced（5G-A / 5.5G）技术的森林火险应急管理系统。系统模拟 5G-A 基站与无人机群的「通感算一体化」能力，在不依赖直视（非视距 NLOS）的条件下探测林区隐蔽暗火，并通过边缘计算在火场一线完成 AI 火势推演与 LBS 救援调度，最终在 WebGIS 数字孪生大屏上呈现火情态势，辅助指挥官实现「科学推演、先发制人」的主动防御。

> 本项目为通信工程专业前沿技术 5G-A 的实战演练作品，详细设计方案见根目录同名 Word 文档。

## 功能特性

- **5G-A ISAC 通感一体化探测**：侦查机编队模拟毫米波通感波束，在 9×9 探测窗口内扫描网格，识别潜伏期暗火（状态 1）并将其转换为已识别明火（状态 3），实现浓烟、夜间、植被遮挡下的非视距探测。
- **环境驱动 AI 火险演进**：基于元胞自动机（CA）模型，融合温度、湿度、风向/风速多要素耦合计算火势蔓延概率，实时生成全场火险分布与风险指数（risk_score）。
- **AI 平行推演与趋势预判**：后端在空闲算力下克隆当前火场快照进行 12 步超前迭代，预测未来 30 分钟火势扩散范围，在地图上投影「预警区」，辅助提前划定隔离带。
- **LBS 实体消防智能调度**：救援机编队采用最近邻贪婪调度策略，自动匹配距离最近的明火点并前往扑救，配合 WebGIS 展示调度路径与处置进度。
- **数字孪生可视化大屏**：基于百度地图 WebGL 与 ECharts，呈现 30×30 / 100×100 元胞网格、无人机实时航迹、预警覆盖层、风险指数折线与调度日志。
- **边缘智算性能监控**：终端实时打印边缘推演延迟、CA 演进频率、累计探测火点与扑救次数，验证 URLLC / MEC 架构的毫秒级闭环。

## 快速开始

### 环境要求

- Python 3.8+
- 依赖库：`fastapi`、`uvicorn`、`pydantic`、`requests`、`asyncio`

### 安装依赖

```bash
pip install fastapi uvicorn pydantic requests
```

### 启动后端服务

```bash
uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

### 启动前端大屏

使用浏览器直接打开 `index.html`，或将其部署到任意静态服务器。

### 运行流程

1. 在网页左侧面板设置**风向**、**侦查机编队规模**、**救援机编队规模**；
2. 点击「启动仿真」按钮，系统初始化网格并调用后端 `/api/start` 接口；
3. 观察数字孪生大屏中火势蔓延、无人机巡检/扑救、预警区投影与调度日志；
4. 点击「开启 AI 预测推演」查看未来火势扩散趋势；
5. 当全局风险指数归零时，仿真自动结束。

> 后端启动时控制台每 3 秒打印一次「5G-A MEC 实测性能指标」验证报告，展示边缘推演延迟、演进频率等关键数据。

## API 说明

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/start` | 启动仿真，接收 `wind`、`scout_count`、`rescue_count` 参数，并获取 NASA 卫星火点或随机起火点 |
| `GET` | `/api/state` | 获取完整系统状态（网格、无人机编队、风向、风险指数、性能指标等） |
| `GET` | `/api/predict` | 返回未来 30 分钟火势扩散预测坐标集与预估过火面积 |

### `/api/start` 请求体示例

```json
{
  "wind": "North",
  "scout_count": 5,
  "rescue_count": 8
}
```

## 性能指标

| 指标项 | 设计目标 |
| --- | --- |
| 边缘智算单次推演延迟 | < 10 ms（URLLC 工业标准） |
| CA 模型实时演进频率 | ≥ 5 Hz |
| 调度指令下发决策耗时 | < 1 ms（边缘 UPF 本地分流直连） |
| 火源定位精度 | ≤ 0.8 m 厘米级（5G-A ISAC 毫米波 + CSI 指纹） |
| 火情识别准确率 | ≥ 98% |
| 虚警率 | < 2%（CFAR 恒虚警抑制） |
| 态势同步延迟 | < 20 ms（WebSocket 实时同步） |
